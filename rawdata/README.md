# Local Raw Inputs

This directory is intentionally empty in version control.

Place authorized auxiliary inputs here only when an analysis program reads them directly, preserving the expected filenames. The historical raw-data construction workflow is intentionally not distributed. Access and use remain governed by the provider’s terms.

Never commit raw data, source archives, identifiers, precise locations, restricted GPS material, or extracts derived from them. See [../DATA_AVAILABILITY.md](../DATA_AVAILABILITY.md).
