# Third-Party Components and Dependency Notes

This file records third-party components visible in the code tree. It is a provenance aid, not a license grant or a complete legal determination.

## Stata dependencies installed separately

No SSC or other third-party Stata package is vendored in this repository. This avoids republishing an incomplete historical dependency snapshot without its accompanying license files.

The analysis uses community-contributed commands supplied by the following upstream packages:

- `_gwtmean`, `carryforward`, `coefplot`, `ineqdec0`, `mat2txt`, `randtreat`, `strdist`, `texdoc`, `tsegen`, and `winsor2` from their same-named SSC packages;
- `estout`, `esttab`, `eststo`, and `estadd` from the SSC `estout` package;
- `multproc` from the SSC `smileplot` package;
- `scheme-tufte.scheme` from the SSC `scheme_tufte` package;
- `project`, `ivreg2`, `ranktest`, `outreg2`, and `insobs` from their same-named SSC packages; and
- `grc1leg` from Stata's official user archive at <https://www.stata.com/users/vwiggins/>.

The convenience installer in `scripts/install_stata_dependencies.do` retrieves these components from their upstream Stata distribution channels, and `scripts/preflight.do` checks availability. Each component remains governed by its upstream license and copyright notice. Installation does not transfer ownership or alter those terms. The installer retrieves current versions rather than reconstructing a version-pinned historical environment, so record the actual installed versions for archival replication.

## Project-specific Stata helpers

The top-level `ado/` directory retains six project-specific or separately sourced helper programs from the publisher-distributed source, including spatial-HAC and radius-selection routines. The source materials used for this packaging did not include a uniform license covering those files; they are not relicensed here. See [NOTICE.md](NOTICE.md) before reuse or redistribution.

## R dependency management

The repository contains:

- `renv.lock`, which records R package versions and sources;
- `renv/activate.R`, an activation script generated by the `renv` project;
- `renv/settings.dcf`, project settings for `renv`.

The vendored `renv/activate.R` bootstrap is distributed under the MIT License; its notice is preserved in [`LICENSES/renv-MIT.txt`](LICENSES/renv-MIT.txt). Each R package restored by `renv` is governed by its own license. Inspect the package metadata in the restored library before redistribution. The lockfile is an environment manifest; it is not a collective license for the packages it names.
